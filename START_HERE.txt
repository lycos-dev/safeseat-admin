SAFESEAT ADMIN V1.5 — MOBILE / FIREBASE INTEGRATION
===================================================

This Admin build is paired with the updated SafeSeat mobile app and uses the
same safeseat-app Firebase project.

IMPORTANT: Your existing Firebase Authentication Admin login is kept. You do
not need to recreate it if you can already sign in.

1) Open PowerShell in this folder and install packages:
   npm install

2) Create .env from .env.example if this checkout does not already have your
   local .env. Keep:
   VITE_DATA_MODE=firebase

3) DEPLOY THE UPDATED FIRESTORE RULES before testing the mobile integration:
   firebase login
   firebase use safeseat-app
   firebase deploy --only firestore:rules,firestore:indexes

   If Firebase CLI is not installed:
   npm install -g firebase-tools

4) If the old synthetic Firebase dataset is still present, place your private
   service-account.json in this folder temporarily and run:
   npm run clear-firebase-demo

   service-account.json is Git-ignored. Never commit or send it.

5) Start Admin:
   npm run dev

6) Start the paired mobile app, sign in, assign the SafeSeat hardware seat, and
   begin monitoring. Real privacy-minimized records will then populate:
   - account_directory
   - vehicles
   - hardware_status
   - monitoring_sessions
   - incidents (only on a real Main Hub emergency)

No exact HR, RR, temperature, FSR values, MPU samples, or camera frames are
written to the Admin collections.

Read SAFESEAT_V1.5_MOBILE_INTEGRATION_NOTES.md for the integration details.
